# BeyondTranslate

**BeyondTranslate** (formerly **Biyi**) is a translation app. Translate text from screen selections, screenshots, your clipboard, or direct input.

[Download](https://beyondtranslate.com/)

## Features

- **Screen selection:** Capture and translate text from desktop apps with global shortcuts.
- **Screenshot OCR:** Recognize and translate text in images and other areas where text cannot be selected.
- **Multiple translation services:** Choose traditional translation engines or LLM providers to suit your needs.

## Source Code

New versions of BeyondTranslate are no longer open source. This repository provides product information and download links.

Source code for earlier open-source releases is available on the [`legacy` branch](https://github.com/beyondtranslate/beyondtranslate-ce/tree/legacy).
