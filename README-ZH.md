# BeyondTranslate

**BeyondTranslate**（原名 **Biyi**）是一款便捷的翻译应用。通过屏幕取词、截图、剪贴板或直接输入，随时获取翻译结果。

[下载](https://beyondtranslate.com/)

## 功能

- **屏幕取词：** 通过全局快捷键，从桌面应用中获取并翻译选中的文本。
- **截图 OCR：** 识别并翻译图片及其他无法直接选取的文字。
- **多种翻译服务：** 按需选择传统翻译引擎或大语言模型服务。

## 源码说明

BeyondTranslate 的新版本不再开源。本仓库用于介绍项目并提供下载入口。

旧版开源代码可在 [`legacy` 分支](https://github.com/beyondtranslate/beyondtranslate-ce/tree/legacy)查看。
